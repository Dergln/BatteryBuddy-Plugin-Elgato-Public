# BatteryBuddy Stream Deck Plugin 1.3.0

- Shows the selected device's BatteryBuddy category icon inside the live
  four-segment battery ring.
- Defaults to an icon-only key with no generated title; custom titles remain
  available.
- Includes the plugin-specific ring colours and refreshed Stream Deck action
  icons introduced in 1.2.0.
- BatteryBuddy and its named-pipe protocol are unchanged.

Requires BatteryBuddy 1.0.5 or newer and Stream Deck software 7.1 or newer.
Install the `.streamDeckPlugin` asset by opening it in Stream Deck. No Elgato
Marketplace submission is implied.

Verify the installer against `SHA256SUMS.txt`. Source and GPLv3/MIT licence texts
are included in the repository and installer as applicable.
